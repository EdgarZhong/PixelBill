# Agent B 分发单：Engine Consumption Scope

## 1. 任务目标

改造 AI Engine 的消费范围控制：仅消费当前选中账本队列。

## 2. 背景上下文

- 队列已按账本隔离：`classify_queue/{ledger}.json`
- 用户要求：切换账本后优先处理当前账本，旧账本任务停放
- 当前阶段保持 UI 按钮入口，不新增自动触发

## 3. 负责范围（只做这些）

1. 在消费循环中绑定 `currentLedger`
2. 每次消费仅从 `classify_queue/{currentLedger}.json` 拉取任务
3. 账本切换后，消费目标同步切换到新账本
4. 非当前账本队列任务不消费、不删除、不重排

## 4. 禁止越界（不要做）

- 不改触发层场景筛选逻辑
- 不改队列冲突规则（由 Agent A 负责）
- 不改 Prompt 字段结构（由 Agent C 负责）
- 不新增/修改 UI 交互流程

## 5. 建议涉及文件

- `src/core/ai_engine/*`（消费主循环/调度入口）
- `src/core/services/LedgerService.ts`（仅在需要读取当前账本状态时）
- `src/hooks/*`（仅在必要的状态订阅边界内微调）

## 6. 验收标准

1. 当前账本有任务时可正常消费
2. 切换账本后，消费目标立刻切换
3. 非当前账本任务不会被误消费
4. 返回原账本后可继续消费其停放任务

## 7. 交付物

- 消费范围控制代码
- 手工验证步骤（含切账本中断与恢复场景）
- 潜在竞态说明（切换瞬间任务状态一致性）
