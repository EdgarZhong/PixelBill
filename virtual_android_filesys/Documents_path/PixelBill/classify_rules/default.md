# 账本分类规则 (Ledger: default)

此文件定义了本账本中各分类的判定标准。AI 助手将依据此规则对交易进行自动分类。

## 1. Meal (正餐)
仅包含早、午、晚三餐的正餐支出。

**关键特征**:
- **商户类型**: 学校食堂、快餐店、面馆、简餐店。
- **特殊例外**: 
  - 提供简餐的咖啡店（如售卖意面/饭）。
  - 晚间时段 (>20元) 的便利店消费 (视为关东煮/便当)。
  - 个体餐饮商户 (金额/时间符合正餐特征)。
  - 早餐时段的极小额食堂支付 (如给伴侣买豆浆)。
- **补差价**: 正餐使用代金券后的小额补付 (归为 Meal)。

## 2. Others (其他)
包含零食、饮品、娱乐、生活服务、交通以及人均消费过高的“大餐”。

**关键特征**:
- **商户类型**: 奶茶店、水果店、甜品店、纯零食店。
- **生活场景**: 洗衣、打印、超市购物、交通出行。
- **金额阈值**: 单笔 > 70元 (视为大餐/聚餐)。
- **大餐关联**: 针对大餐 (>70元) 的补差价。
- **去重逻辑**: 若同一时段已有一笔明确正餐，紧邻的面包/小吃消费归为 Others。
- **用餐人数**: 仅统计双人用餐 (情侣)；单人外卖/食堂归为 Others。
